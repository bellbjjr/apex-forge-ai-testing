# Apex Forge AI Testing

A visible Selenium test environment for the Apex Forge website, designed to run in GitHub Codespaces and be watched from an iPad through a private noVNC browser session.

The first smoke test verifies Apex Forge branding and exercises a visible same-site navigation link. See [SETUP.md](SETUP.md) for Codespaces, live-browser, authentication, test, and shutdown instructions.

Secrets, screenshots, reports, and browser-session artifacts are excluded from Git.
